# 來打橋牌 · 蜜月橋牌網頁版

打開網址有三條路：

1. **第一次玩？先跟阿元學**：走進台南巷口的小牌店，跟店主阿元玩四幕小故事（約 5 分鐘），學會搶牌、叫牌、王吃、打成 → `/story/`
2. **跟電腦打一局**：對手是阿元（電腦），規則、計分跟連線版一模一樣，整場先到 100 分；重新整理還是同一局
3. **開房跟朋友打**：你按「開房」→ 把房號傳給朋友 → 朋友打開網址輸入房號 → 兩個人各用自己的手機、自己的網路打同一桌

- **雲端負責**洗牌、記輪到誰、判斷誰贏、計分；每支手機只會收到**自己的牌**，誰都偷看不到對方
- 朋友**不用註冊**任何帳號；家裡電腦可以關機
- 重新整理或斷線，回來還是同一桌（座位憑證存在手機上）
- 規則跟 Unity 版一模一樣（② 完整對戰：加倍／再加倍、計分、先到 100 分）

### 美術與手感（Game Feel）

美術照確認過的設計稿：深色木桌、撕紙拼貼的復古紙張、黑金細框、蠟封、阿元郵票（燕尾服貓咪）、綠絨布牌桌、酒紅牌背。素材都是原創向量圖（`public/art/`）。

| 系統 | 檔案 | 做什麼 |
|---|---|---|
| MotionTokens／CardMotion | `src/client/fx.ts` | 統一時長、彈簧曲線（CSS `linear()`）、動畫強度；飛牌（微轉、影子變化）、落桌壓扁回彈、翻牌、輕擺拒絕、局部震動 |
| SoundManager | `src/client/sound.ts` | Web Audio 當場合成的原創音效＋八音盒背景音樂；音效／音樂分開調、一鍵靜音、同時發聲上限、連贏音高微升、手機第一次點擊解鎖 |
| ParticleEffects | `src/client/particles.ts` | 金粉、星芒、紙屑、小花色、印章墨跡；一張 canvas、沒粒子就停、低階手機減半 |
| FeedbackManager／ScoreAnimator | `src/client/feedback.ts` | 依真實事件分三級（一般贏墩／王吃・關鍵一墩／合約達成・擊破・整場勝利）、Hitstop、數字越跑越快的滾動 |

- 手牌：扇形排列、滑鼠移上去升起放大、右邊的牌讓位；點一下選牌（彈一下、轉 ±3°），再點一次或按「出牌」；手機可以把牌往上拖出去
- 出牌：抽出 → 飛到桌面 → 落桌壓扁回彈＋拍桌聲；對手的牌半路翻面
- 叫牌：先選階數再選花色；每一次叫牌像蓋章、叫牌紀錄逐張蓋上去
- 結算：合約 → 目標 → 實得 → 蓋章判定 → 得分 → 明細 → 總分，點一下跳過直接看最終結果
- 所有分數、勝負都來自原本的計分程式；連線版等雲端確認後才演出贏墩和得分
- 手機開了「減少動態效果」會自動用低強度、不震動

**v2 手感細節**

- 選牌：快速抽離、略超過再回彈（約 170ms）；滑過的牌停 45ms 才升起，整排不會抖；還沒輪到你也能先選好
- 出牌三段：抽牌 70ms → 飛行 210ms → 落桌壓到 93% 再彈回；拍桌聲用音訊時鐘排在落桌那一瞬間
- 贏墩分級：一般墩只有順暢的小回饋；王吃／關鍵墩停頓 80ms；合約達成／擊破 100ms；只有整場勝利才全力釋放
- 連續贏墩：音高、數字回彈、桌面金色光暈一點一點遞增，輸一墩恢復
- 不能出的牌：輕擺＋牌上方說明原因（「你手上還有 ♣，這墩要先跟 ♣」），能出的牌亮一下
- 結算：合約、目標、實得、判定一項一拍 → 得分加速 → 總分一次重擊；分數只在整局打完才出現
- 叫牌逐級升溫：1–2 線低、3–4 中、5–6 高、7 最高。籌碼上浮 →（高等級蓄力停頓）→ 落到叫牌紙卡壓縮回彈＋衝擊波；
  雙方一直加碼，契約紙的邊越來越熱，Pass 釋放、重發歸零；加倍是紅色衝擊＋低頻雙擊，再加倍是金紅雙重衝擊波＋短促亮光；
  合約確定時在牌桌中央蓋章，再一次重擊落進上方合約欄（保留加倍）
- 背景八音盒預設很輕（15%），音效改成紙、木、銅片質感
- `node test/e2e/feel-check.mjs`：自動驗收操作反應、不能出的原因、特效分級、影格時間

**情緒張力系統（Pressure → Release）** `src/client/tension.ts`

- 兩個數字分開管：`risk`（真正的合約風險，只看線數與加倍）、`pressure`（情緒張力 0..1，只影響畫面、聲音、動畫）
- 叫牌 Build：叫得越高壓力越大；加倍、再加倍是明顯的跳升；背景陰影加深、牌桌局部聚光、低頻嗡聲浮出來。加碼不放勝利粒子
- Pass：結束叫牌的那一聲不清空壓力，直接帶進合約；開場的 Pass 只稍微鬆一點；雙方都 Pass 重發才歸零
- 打牌 Sustain：壓力跟著公開的墩數走（勢均力敵、快到終點時最繃），不看任何隱藏的牌；合約定案前不放最終勝利動畫
- 合約 Release：對你是好事（你打成，或你擊破對方的合約）才「先收束、再瞬間爆發」，強度看合約風險；對方達成只安靜收掉，不羞辱
- 結算單一打開，桌面就恢復乾淨

**故事教學**：阿元和旁白一句一句講（點一下對話往下一句，也會自己往下；點牌桌可以直接開始），
有開場、每一幕的前情與換幕紙條、出牌後的說明、結尾邀你真的打一局；叫牌用跟正式牌桌一樣的籌碼與合約蓋章演出

### 阿元的四幕故事

| 幕 | 你做什麼 | 學到 |
|---|---|---|
| 01・先來搶牌 | 阿元翻開 ♦K、出 ♣9。你出 ♣Q 搶走 ♦K，或出 ♣4 讓他拿、自己摸暗牌 ♠6。兩種都對，可以「換一張試試」 | 一墩、明牌與暗牌 |
| 02・你敢叫幾墩？ | 13 張手牌，叫 2♥（送出前會說「紅心當王牌，至少要贏 8 墩（6＋2）」），阿元 Pass | 合約、莊家、防守方 |
| 03・王牌派上用場 | 阿元出 ♠A：有 ♠3 就得跟；換一手沒有黑桃時，♥2 王吃或墊 ♣3 都可以 | 跟牌、王吃、墊牌 |
| 04・說到做到 | 7／8 墩，出 ♣A → 8／8、8 比 5，「2♥、沒有加倍、剛好打成，這局 +20 分」 | 打成、倒約、計分 |

每一幕都是一個固定牌局，丟進跟連線版**同一套規則引擎**（`src/game`）：能不能出、誰贏、分數都是引擎算的。阿元的手牌和他摸的暗牌只畫牌背。進度存在手機上（`hb.story.v2`，跟舊版九頁故事的儲存鍵分開），重新整理會回到同一頁。

### 手牌操作：選牌和出牌分開

- **點一下**：選起來（升起約 18px、微微放大、左右的牌讓位，彈簧動畫）；**再點同一張**放下；**點別張**直接換過去
- **手指左右滑**：跟著手指一張一張選（只有輕輕升起和小小的聲音，不會每張都放大動畫）
- **往上拖**：牌貼著手指走，跟著速度微微傾斜；拖到牌桌上放開 → **出牌預覽**（牌停在「你出的牌」那一格、標「預覽」，牌局狀態沒變）；放在別處或往下拉回 → 回到手上；點預覽中的牌也能收回
- **只有按「確認出牌」才會送出**：點牌、雙擊、快速連點、滑動、拖曳都不會出牌；送出後按鈕鎖住，連按也只送一次，朋友連線一樣由伺服器確認
- 不能出的牌也能選起來看，會說明原因，但「確認出牌」按不下去；不是你的回合也能先選牌、拖到桌上試，但不會進預覽
- 手勢用 Pointer Events 判斷：手指移動超過 10px（滑鼠 5px）才算移動；水平為主是選牌、往上為主是拖曳；鍵盤用 Enter／空白鍵選牌、左右鍵換牌
- 對戰畫面固定在可視範圍（`100dvh`、安全區域），不會捲動、不會被拖動、不會選到文字；矮的手機直拿時，出的兩張牌改左右並排；橫拿時牌桌在左、手牌和按鈕在右。首頁、教學、設定照常可以捲

### 出牌重量感與局勢衝擊（Impact Tier 0–4）

「每一張牌都有重量，但只有真正重要的牌，才能撼動整張牌桌。」分兩層，互不搶戲：

- **Layer A 出牌本體**（`src/client/impactfx.ts` 的 `pullUp → slamFly → contact`）：牌一出就演——抽離（60ms，紙張摩擦聲）→ 加速飛向桌面（約 200ms，越接近桌面越快）→ 接觸壓扁（約 55ms）→ 回彈（約 125ms），桌面接觸陰影往外擴散；拍桌聲（高頻拍擊＋低頻重量）跟落桌排在同一個音訊時鐘上。大牌、王牌、加倍局稍微重一點（`playWeight`），但只是手感，不代表這墩已經贏了
- **Layer B 牌局結果**（`presentImpact`）：只有規則確認誰贏這墩（`TrickWon`）才演，強度看 `src/client/impact.ts` 的 `evaluateTrick`（純計算、有單元測試）：

| Tier | 什麼時候 | 演出 |
|---|---|---|
| 0 一般出牌 | 每一張牌落桌；搶牌時拿到普通明牌 | 壓扁、陰影、回彈、拍桌聲 |
| 1 強力出牌 | 已確認的一般贏墩；搶到 J 以上的明牌 | 贏的牌再壓一下、小環形衝擊、陰影更深、只抖那張牌；不裂 |
| 2 特殊出牌 | 王吃；背水一墩（需要剩下每一墩、拿下來了）；加倍局「再一墩就定案」 | 短定格、淡淡壓痕、細裂紋、王牌花色紋樣、牌桌輕震、低頻重擊 |
| 3 關鍵出牌 | 這一墩讓合約確定打成，或確定倒約（防守方拿到 14−目標墩數，當下就判，不等最後一墩） | 60–100ms 定格、桌面下沉、墨線裂紋、雙衝擊波、旁邊的牌一起抖、事件文字，接著釋放叫牌累積的壓力 |
| 4 決勝爆發 | 加倍／再加倍或 7 線的合約打成；這一墩保證的分數讓一方拿下整場（本來落後就是「逆轉」） | 更長定格、強烈下沉、金色裂紋、合約欄與墩數亮起、成功回響，接續結算動畫 |

- 不盲目累加：先依主要事件定等級（整場勝負 > 合約定案 > 背水／再一墩 > 王吃 > 一般贏墩），其他條件只做有限加成；同一墩只有一個高潮，合約定案時「重擊 → 定格 → 裂紋」之後才交給 EmotionDirector 釋放（不重複震、不重複閃光）
- 結果對你不好（對方打成、你被倒約）時用沉重版：灰暗的圈、黑色裂紋、下沉更慢、往下掉的低音，沒有粒子和歡慶
- 裂痕、壓痕、陰影畫在牌桌裡、牌的下面（不會蓋住數字和花色），位置用當下卡牌的實際位置算；每個特效元素 300–650ms 後移除，不會累積
- 「簡化」動畫（系統開了減少動態效果時的預設）不畫裂痕、壓痕、下沉、大衝擊波，也不震牌桌；「關閉」只留聲音、文字與必要提示
- 朋友連線：落桌和結果都由伺服器確認的事件驅動，同一墩只演一次（`ImpactGate`），兩支手機看到的衝擊等級一樣，判斷只用公開資訊
- 音效都是 Web Audio 合成；想換成錄好的音效檔，把檔案放到 `public/sfx/`，在 `src/client/sound.ts` 的 `SAMPLE_URLS` 填網址即可

### 文案與阿元的台詞

- 語氣：外表英式復古，裡面的人講話自然；系統字簡短，阿元像坐在對面的玩家。台詞放在 `src/story/script.ts`（教學）和 `src/client/main.ts`（牌桌、叫牌、結算、連線提示）
- 台詞一律跟著真的發生的事：叫牌的墩數、合約、誰先出、摸到哪張暗牌、能不能王吃、打成／倒約幾墩、加倍幾次，都從規則引擎的狀態算，不寫死
- 跟阿元打的時候，他會在自己旁邊冒一個小紙條講兩句（`aheSay`）：一般贏墩大多不講，王吃、關鍵墩、連贏、快打成才開口；講完一句至少隔 6 秒、同一句 45 秒內不重複，不擋操作。朋友連線時對面是真人，不會出現阿元的名字、郵票或台詞
- 整場結束的「險勝／大勝」：分差 20 分以內是險勝，60 分以上是大勝（`CLOSE_MARGIN`、`BIG_MARGIN`）

## 部署到 Cloudflare（第一次大約 5 分鐘）

用 Cloudflare 的「接 GitHub」功能，不用把任何密碼交給別人。之後每次 push 到這個分支，網站會自動更新。

1. 登入 [Cloudflare 後台](https://dash.cloudflare.com/) → 左邊 **Workers & Pages** → **Create** → 選 **Import a repository**
2. 連結 GitHub，選 `funcy0184-bit/bridgecard`
3. 設定這幾格（其他保持預設）：

   | 欄位 | 填什麼 |
   |---|---|
   | Project name | `bridgecard`（**一定要跟 `wrangler.jsonc` 裡的 `name` 一樣**） |
   | Production branch | `feature/web-online-v1` |
   | Root directory（Path） | `web` |
   | Build command | 留空（`wrangler.jsonc` 裡已經寫了） |
   | Deploy command | `npx wrangler deploy`（預設值） |

4. 按 **Deploy**。跑完會給你一個網址，長得像 `https://bridgecard.你的帳號.workers.dev`
5. 用手機打開那個網址 → 開房 → 把房號傳給朋友

### 換成這一版（來打橋牌）

已經照上面部署過的話，只要把生產分支換掉：Cloudflare 後台 → Workers & Pages → `bridgecard` → **Settings** → **Build** → **Branch control** → Production branch 改成 `feature/web-story-v1` → 存檔，再到 **Deployments** 按一次重新部署（或等下一次 push）。

想退回原本的連線版：把 Production branch 改回 `feature/web-online-v1` 就好，兩條分支都保留著。

> 後台的按鈕名稱 Cloudflare 偶爾會改。找不到的話，跟 Claude 說你卡在哪一步、畫面上有哪些選項。

### 費用

兩個人玩完全在免費額度內：免費方案每天 10 萬次請求，「房間」用的是免費方案也能用的 SQLite 版 Durable Objects。一局牌大約幾百則訊息。

## 測試站（跟正式站完全隔離）

`wrangler.jsonc` 裡有一個 `staging` 環境：Worker 名字是 `bridgecard-staging`，所以房間、戰績、頻率限制用的是**另一套 Durable Object**，跟正式站的資料互不相通；網址是 `https://bridgecard-staging.<帳戶子網域>.workers.dev`，頁面最上面會有一個「測試站」小標。正式站的自動部署只跑預設環境，不會碰到它。

建立方式（二選一）：

1. Cloudflare 後台 → Workers & Pages → 建立 → 匯入 GitHub repo（同一個 repo）：
   - Worker 名稱填 `bridgecard-staging`
   - 根目錄填 `web`
   - 分支選 `feature/laststand-v1`（之後這個分支一推上去就自動更新測試站）
   - 部署指令填 `npx wrangler deploy --env staging`
2. 自己的電腦（已經 `npx wrangler login`）：

```bash
npx wrangler deploy --env staging
```

## 梭了啦 單人測試（開發者用：真人 vs 測試 AI）

不用找第二個人，一支手機就能把梭了啦的 9 墩、翻轉、保命、讀心、鎖牌、下注、結算、動畫和畫面全部測一遍。**這是開發測試工具，不是新的競技模式。**

- 進入：梭了啦選單 →「跟 AI 試打一局」（入口有沒有出現，見下面的開關）
- 整場在手機上跑（`src/client/laststand-solo.ts`）：規則用同一份引擎、AI 用 `src/laststand/ai.ts` 的六套策略，**只看得到 AI 自己那一邊**；不開房、不連網路、不寫正式戰績，存檔只放在這支手機（`hb-laststand-ai-v1`，不碰經典單機和朋友連線）
- 畫面上一直標著「單人測試｜不計正式戰績」；等待室不顯示房號、玩法、邀請
- 牌桌選單 →「測試工具」：目前第幾墩／階段／輪到誰、AI 策略（保守、激進、隨機、詐唬、留牌、均衡；是打法類型，不是難度）、AI 速度（一般 0.6～1 秒／快速／不等）、跳過 AI 等待、第 1 墩宣戰權（照 seed／我先／AI 先）、同一副牌重來、換下一副牌、指定 seed 重開、測試紀錄（可以複製；不含暱稱、賭上之物、AI 沒公開的牌）
- 同一個 seed、同一場一定是同一副牌；中途重新整理會接著打（網址 `/?lsai=1`）

### 入口開關（建置時決定：`LS_AI`）

| 值 | 效果 | 預設 |
|---|---|---|
| `on` | 入口一直看得到 | 自己電腦上 `npm run build`／`npm run dev` |
| `dev` | 入口藏起來；這支手機開過一次 `/?dev=1` 才出現，`/?dev=0` 收回去；直接打 `/?lsai=1` 也進不去 | Cloudflare 自動部署（Workers Builds） |
| `off` | 整段程式不打包（正式版的 app.js 裡沒有單人測試，小 32 KB） | 要的話在 Workers Builds 設 |

改法：Cloudflare 後台 → Workers & Pages → `bridgecard` → Settings → Build → Variables and secrets（建置變數）加 `LS_AI` = `on`／`dev`／`off`，下次部署生效。

**安全性**：單人測試沒有任何伺服器權限（不開房、不呼叫 `/api`、不開 WebSocket、不碰 Durable Objects、不寫戰績），也沒有改牌、改籌碼、強制結算的介面，所以就算被一般玩家打開，最多是在自己手機上跟 AI 打一場不算數的牌。
- `dev` 只是把入口藏起來（不是門禁）：知道 `/?dev=1` 的人都打得開，但打開了也沒有任何特權
- `off` 是「只納入開發建置」：正式網站的程式裡根本沒有這段
- 真正的存取驗證（例如 Cloudflare Access 只放行你的帳號）要另外開一個網址或路徑來保護；只有將來加了「有特權的開發功能」才需要，這次不需要

## 架構

```
手機 A ──┐                         ┌─ Room（Durable Object，一個房間一個）
         ├─ WebSocket ─ Worker ────┤    · 持有真正的牌局（src/game）
手機 B ──┘   /api/rooms/:code/ws    │    · 檢查每個動作合不合法
                                    │    · 每個座位只送它看得到的事件和牌桌
                                    └─   · 狀態存雲端，睡著再醒來也不會掉
```

| 資料夾 | 內容 |
|---|---|
| `src/game/` | 規則：牌、跟花色、王吃、叫牌（含加倍）、計分、整場勝負、簡單電腦。跟 Unity 版 `Logic/` 一一對應，雲端和手機共用 |
| `src/server/` | `worker.ts` 開房、查房、轉接 WebSocket；`room.ts` 房間本體；`protocol.ts` 手機 ↔ 雲端的訊息格式 |
| `src/client/` | 手機畫面：`main.ts` 牌桌與流程、`fx.ts` 動畫與回饋（含牌桌顏色）、`net.ts` 連線與自動重連、`solo.ts` 單機（電腦在手機上跑，對牌桌來說跟雲端連線長得一樣） |
| `src/story/` | 阿元的故事：`script.ts` 四幕牌局與台詞（不碰畫面，測試直接跑）、`main.ts` 故事頁的牌桌、動畫、進度 |
| `public/` | `index.html`、`style.css`；`app.js` 由 `npm run build` 產生（部署時自動跑） |
| `public/story/` | 故事頁 `index.html`、`story.css`、茶杯 `teacup.svg`（取自故事素材包）；`story.js` 由 build 產生 |
| `public/art/` | 原創向量素材：阿元郵票 `stamp-ahe.svg`、蠟封 `seal.svg`、迴紋針 `clip.svg`、金框角飾 `corner.svg` |
| `test/` | 規則測試、兩支手機的端對端測試 |

### 動畫與回饋（對應 Unity 版的手感）

出牌飛行落地「啵」、對手的牌飛出來途中翻面、贏墩金光後收走、明牌翻面與搶走、暗牌從牌堆飛到手上、王吃大字＋震畫面、加倍／再加倍抖字、「輪到你」Q 彈字、出錯牌抖一下、打成波浪字、分數滾動、整場勝利彩帶；Android 會配合手機震動。選單裡可以調動畫速度、關掉畫面震動和手機震動；手機開了「減少動態效果」會自動收斂。
