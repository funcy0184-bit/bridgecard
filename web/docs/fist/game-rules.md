# 規則現況（v4）

> 數字以 `web/public/fist/src/config.js` 為準；這份是給人看的摘要。Gemini 要改數字 → 在 `feel-plan.md` 提案，Claude 同步進 `config.js` 後更新這裡。

## 基本
- 2 人、**7 格擂台**，開局站第 3、5 格；各 **3 條命**。
- 損傷 % 越高，被擊飛越遠：`擊飛初速 = 150 × (1 + 損傷/100)`，角度 48°、重力 900；飛出畫面 26px 外＝掉一命。
- 實際上 110%～140% 以上才容易一擊出場。
- 位置只會被「推」改變（沒有走位）：重擊推 1 格、四套拳每拳推 1 格、反擊換位、擊飛落點。

## 一回合流程
```
猜拳 2.8s ──► 開牌 0.55s ──► 結果
 （前 2.2s 亮招：對手看得到你擺的架式、可以一直換）
 （後 0.6s 藏招：雙方變黑影，最後一下才是真的）
 （時間沒到前，就算兩邊都按了也要等滿）

贏 ─► 連勝 +1
      連勝 1、2：單發重擊 0.7s（+8%、推 1 格、頓幀 90ms）
      連勝 3：🔥 爆發 1.1s → 四套拳
               每拳：攻方選拳 0.55s → 守方反擊窗 0.9s → 命中 0.35s
               傷害 5／5／5／9%，第 4 拳擊飛 ×1.15
               守方按「剋制那一拳的手勢」＝反擊：連打中斷、反打 +10%、擊退 1 格
輸 ─► 連勝歸零
平手 ─► 連勝不動，拼刀蓄力 +1
      第 1 次：小拼刀「叮！」0.75s
      累積 2 次：五連斬 → 3.5s 內預輸入 5 招 → 由慢到快自動對砍
                → 贏比較多刀的一方放大招（+24%，搶先手再 +6%，統一擊飛 48°×1.3）
```

## 其他規則
- **過熱**：分出勝負後，雙方剛出的那招下一輪不能出（拼刀結算、掉命重生後解除）。
- **越打越快**：每 3 回合升一級（最多 Lv.4）：亮招 2.2→1.6s、藏招 0.6→0.5s、攻方選拳 0.55→0.45s、反擊窗 0.9→0.75s。
- **模式**：同機雙人、對 AI（分級）、線上房間、教學道場、🛠️ 訓練場。

## 節奏估算（開局速度）
| 事件 | 花費時間 | 造成傷害 |
|---|---|---|
| 一次普通猜拳贏 | ≈ 2.8 + 0.55 + 0.7 ≈ **4.1s** | 8% |
| 平手一次 | ≈ 2.8 + 0.55 + 0.75 ≈ **4.1s** | 0 |
| 一整套四套拳（含爆發） | ≈ 1.1 + 4 × 1.8 ≈ **8.3s** | 24%＋擊飛 |
| 五連斬（含輸入） | ≈ 3.5 + 0.3 + 1.6 + 大招 ≈ **6～7s** | 24～30%＋擊飛 |
