# 逆命賭局 P1：可玩版本驗收紀錄

分支：`feature/laststand-v1`（**還沒合併、沒有部署**；正式網站上沒有逆命賭局）

## P1 做了什麼

- 兩個真人用既有的房間、暱稱、斷線重連系統，從開房打完九墩（或有人籌碼歸零）、再戰
- 底注採方案 B：第 1–3 墩底注 1／上限 3、第 4–6 墩 2／4、第 7–9 墩 3／可梭哈（A、C 留在 `rules.ts` 方便比較）
- 位置：保留宣戰權逐墩輪替；**再戰交換第 1 墩宣戰權**；每場紀錄都存「第 1 墩誰有宣戰權」和勝負（之後算位置勝率用）
- 中間牌沒有加特殊能力
- 賭局契約書：各自填、占位句輪播（聚焦／輸入中／已填／減少動態時停止）、即時預覽、留空＝「我最後的尊嚴」、「本人同意（應該）」蓋章；等待室和結算都看得到雙方賭上之物（只是遊戲敘事）
- 手機牌桌一個畫面放得下：雙方籌碼、剩餘大中小、本墩比大／比小與下一墩、底注／上限、雙方已投入、疊池、輸贏試算（若接戰／若棄牌）、輪到誰、對手狀態（已鎖牌／過牌／加注到幾／梭哈）、自己的手牌和按鈕
- 梭哈按鈕寫「梭哈：每人押 X」，說明是「每人押到雙方較少的籌碼」，不是各自全推
- 隱藏資訊：每個人只收到自己的牌；對手鎖的牌在翻牌前只看得到「已鎖牌」；棄牌墩只公開大中小；讀心結果只送給用的人
- 每墩的事件都有編號保存，P2 文案系統直接用

## 已知問題與還沒做的

1. 對手出手時的提示條（例如「大雞梭哈：每人押到 8 枚」）會蓋住對手那一格 2–3 秒（提示條內容跟那一格一樣，收起來就看得到）
2. 賭上之物只擋 HTML 符號、網址、email、電話、控制字元；**沒有髒話／人身攻擊過濾**，對方會看到你打的字
3. 真機項目還沒測：iPhone 注音選字、Android 中文輸入、鍵盤跳出、LINE 內建瀏覽器、鎖螢幕／切背景（清單在 `test/MANUAL-online.md` 的 C3）
4. 位置勝率：資料有存（每場的玩法、第 1 墩宣戰權、勝負、雙方籌碼），還沒有統計畫面或報表
5. 逆命賭局沒有「精彩回顧」（經典牌局才有）；選單裡的同桌戰績會分玩法計算
6. P2／P3 還沒做：嘴砲文案、賽後報告、大型特效
7. 之後的平衡分析（還沒做）：座位與宣戰權勝率、加注後對手棄牌率、拿大／中／小牌加注的成功率、中間牌在唬牌／消耗對手強牌／保留高價值牌的實際戰術價值、第 7–9 墩逆轉頻率、同一副牌交換座位與先手後的結果
