# 梭了啦！這局賭什麼？ P1.5：UI 改版與驗收紀錄

分支：`feature/laststand-v1`（**沒有合併、沒有部署**；正式網站沒有任何變動）
程式代號照舊是 `laststand`（舊名「逆命賭局」），房間、戰績、規則引擎的資料格式都沒改名。

## 這一版做了什麼

### 1. 新玩法正式更名
- 玩家看得到的地方一律是「梭了啦！這局賭什麼？」：首頁入口、新玩法選單（兩行標題＋「輸了交出來。」）、等待室玩法按鈕、邀請連結簡介、換玩法提示、伺服器錯誤訊息
- 程式註解也統一改稱梭了啦（`rules.ts` 開頭留一句「舊名逆命賭局」方便對照）

### 2. 首頁雙玩法入口＋轉場
- 封面標題下面兩個並排入口：經典橋牌（深綠牌桌）／梭了啦！這局賭什麼？（酒紅暗金、「新玩法」小標）；iPhone SE 第一個畫面就看得到
- 點梭了啦：約 0.6 秒轉場（綠牌桌暗下 → 中間的牌翻面成「梭」→ 背景換酒紅暗金 → 標題換成新玩法）→ 新玩法選單；只動 transform／opacity
- 動畫關閉或系統「減少動態效果」：不播轉場，直接換畫面
- 新玩法選單：找朋友開一局（開好的桌自動是梭了啦）、輸入房號加入、怎麼玩（規則小抄）、回經典橋牌；瀏覽器上方顏色跟著換
- 網址 `/?play=shuo` 直接打開新玩法選單（分享、測試用）

### 3. 阿禾 → 阿元
- 所有玩家看得到的「阿禾」都改成「阿元」（首頁、教學四幕、對局台詞、結算、設定、郵票圖、網頁描述）
- 「跟阿禾學」「跟阿禾打」合併成一顆「跟阿元玩」：
  - 第一次按：阿元問「要我先教你怎麼玩嗎？」→「先教我一下」進教學（教完最後一步直接開打，不繞去章節）／「直接開打」
  - 教學打完過（新版或舊版 v3 存檔都算）、問過了、或有一局打到一半 → 直接開打
  - 「重新教學」：首頁選單＋下面四張章節卡
- 存檔鍵都沒換（`hb.story.v4`、`hb.story.v3`、`hb-story-offered`、單機存檔），舊手機上的進度照樣認得

### 4. 賭局契約書
- 固定標題「賭局契約書」、固定欄位名「賭上之物」、副標「想要贏，那必須得輸得起。」
- 提示句 19 句（一字不差）隨機輪播：每 3～4 秒（含淡出）換一句、不連續重複、一輪全部輪過才重洗；聚焦、打字、有字、動畫關閉／減少動態時停止，不會蓋掉玩家打的字
- 新增「賽前豪言」（選填、最多 30 字）：預覽「本人自願於本場賭局中賭上『…』。賽前豪言：「…」」、雙方名牌都看得到；伺服器存檔（P2 戰報用）
- 內容限制：賭上之物 24 字、豪言 30 字；擋網址、email、電話、HTML／程式碼符號、控制字元，**新增太衝的髒話與歧視字眼**（去掉空白標點再比對，日常的「幹嘛」不誤擋）
- 「本人同意（應該）」蓋章、雙方確認照舊；賭上之物仍只是遊戲敘事

### 5. 操作修正
- 對手出手時的提示條改到最上面的標題列、從上方落下，不蓋對手那一格、不蓋選單鈕
- iOS 安全區域：牌桌、等待室、新玩法選單左右讓開瀏海（橫拿）；底部固定操作列讓開 Home 指示條
- 規則小抄的「知道了」釘在底部，小手機不用捲到底
- 名牌裡 24 字的賭上之物最多兩行，不撐破版面

### 6. 測試站（準備好、暫緩部署）
- `wrangler.jsonc` 加了 `staging` 環境：Worker 名稱 `bridgecard-staging`＝另一套 Durable Object（房間、戰績、頻率限制完全分開）；頁面上方會出現「測試站」小標
- `npx wrangler deploy --env staging --dry-run` 通過；**依指示暫緩，沒有建立 API Token、沒有部署**；建立方式寫在 README「測試站」
