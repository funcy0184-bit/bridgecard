# 梭了啦 P2.5：遊戲體驗重構（規劃與 P2.5-A 規格）

分支：`feature/laststand-p25`（從 P2 上線後的開發分支 `76f0b92` 開出來；正式網站是 `8447325`）。**只規劃、還沒動程式；不部署。**

核心目標：讓玩家覺得自己在**打牌**，不是在填網頁表單。

## 0. 現況分析（看過程式碼和畫面）

### 0.1 畫面結構（`public/index.html` 的 `#lstable`、`src/client/lstable.ts`）

```
#lstable（可捲動的直欄）
├─ header.lsbar      第幾墩＋底注上限＋單人測試標籤＋選單鈕；P2 的轉播字幕蓋在這裡（#lsTicker）
├─ #lsOpp            對手：名字、角色、狀態、籌碼、「剩 N 張：大x・中y・小z」、技能文字
├─ #lsDir            本墩「比大／比小」大字＋下一墩
├─ #lsPot            雙方已投入（文字）、疊池（文字）、上一墩結果（#lsReveal：兩張小牌＋一句話）
├─ details#lsLog     每墩紀錄（展開會把版面往下推）
├─ #lsCast           P2 節目小卡（fixed，量空位放）
└─ #lsDock（sticky 底部）
   ├─ #lsMe          自己：角色、籌碼、剩幾張大中小、技能
   ├─ #lsTurn        一句「輪到誰／做什麼」
   ├─ #lsHand        9 張牌一排、每張下面寫「大／中／小」；鎖了的牌留在手牌裡標「已鎖」
   ├─ #lsRisk        輸贏試算（2 行）
   └─ #lsActions     按鈕（innerHTML 每次重畫）＋說明小字
```

- **畫法**：`lsView()` 每收到一個新的牌桌（LSView）就整個 `render()`：手牌 `replaceChildren`、按鈕 `innerHTML`。**沒有持久的牌／籌碼節點**，所以沒辦法做「這張牌從手上飛到桌上」這種動畫
- **事件**：伺服器送 `ack → room → lsEvent → lsState`。lstable 目前只拿事件來跳提示條（對手翻轉、保命、讀心、梭哈、退款、歸零）
- 可用的公開事件：`TrickStart`、`Flip`、`Safeguard`、`Locked`（誰鎖了，不含牌）、`LockedCard`（**只送給本人**）、`Ante`、`Check`、`Raise`、`Call`、`Fold`、`Insight`、`Showdown`（翻牌：雙方牌面）、`FoldReveal`（棄牌：只有大中小）、`Settle`、`PoolAdd`、`PoolRefund`、`Eliminated`、`MatchOver` → **做動畫需要的資訊都已經有，不用改協定**
- 斷線回來（resync）只給最新快照、不補播 → 動畫一律「看到事件才演、快照只擺好位置」

### 0.2 動畫、音效、效能（已經有、可以直接用）

| 模組 | 現有能力 | 梭了啦有沒有用 |
|---|---|---|
| `fx.ts` | `fly`（弧線飛行、半路翻面）、`pin`、`land`（壓縮回彈）、`flipTo`、`shockwave`、`punch`、`glow`、`countUp`；動畫強度／加快／減少動態設定 | 只用 `cardEl` |
| `impactfx.ts` | 經典出牌的「拉起 → 甩出 → 落桌 → 回彈」三段（`pullUp`、`slamFly`、`contact`） | 沒用 |
| `sound.ts` | 合成音效：`lift`、`slap`、`land`、`faceUp`、`swish`、`boom`… | 沒用；**沒有籌碼音** |
| `perf.ts` | 依實際幀時間自動降特效品質 | 只在經典牌桌開 |
| `tension.ts` | 壓力氛圍、聚光 | P2 用自己的壓力暗角 |

### 0.3 問題（對照 `p25/base-ls-*.jpg` 現況圖；經典牌桌 `p25/base-classic-390.jpg` 是美術方向參考）

1. **沒有「桌子」**：中間只有大字方向和一條「已投入」文字，牌和籌碼都不在桌上；底部固定區占畫面 55～60%
2. **表單感**：面對加注時最多 6 個按鈕＋2 行試算＋1 行說明，全部一樣大
3. **鎖了的牌還在手牌裡**（標「已鎖」），沒有「把牌蓋到桌上」的動作
4. **籌碼只是數字**：底注、加注、接戰、收底池都沒有東西在動
5. **大中小說太多次**：對手「剩 9 張：大3・中3・小3」、自己同一句、每張牌下面又寫一次、讀心按鈕又寫一次
6. **流程不聚焦**：輪到誰、要做什麼、試算、提示四處都有字
7. **轉播搶位置**：字幕蓋標題列、小卡塞在中間空位；小螢幕常常沒空位

### 0.4 測試覆蓋（重構時要一起改）

- 依賴 lstable 結構的瀏覽器測試：`laststand-ui`、`laststand-layout`（六種大小 × 每個階段：重要資訊都在畫面裡、沒被底部區蓋住）、`lsai-ui`、`p15-ui`（提示條不蓋對手）、`p2-cast`（量 `#lsOpp`、`#lsDir`、`#lsPot`、`#lsLog`、`#lsDock`、`#lsBar` 的位置）
- 它們用到的選擇器：`#lsActions [data-a=…]`（全部按鈕）、`#lsHand .lscard`、`#lsMyChips`、`#lsOppChips`、`#lsOppCounts`、`#lsDirBig`、`#lsDirNote`、`#lsStage`、`#lsRisk`、`#lsTurn`、`#lsTrick`、`#lsReveal`、`#lsLog`、`#lsMenuBtn`、`#lsTestTag`、`#lsOppName`
- **策略**：`data-a` 按鈕名稱、`__hbLS()`、`__hbCast()` 驗收掛鉤保持不變；其他 id 盡量沿用，新增區塊用新 id，測試跟著改；不碰規則、伺服器、AI、導演的單元測試

## 2. P2.5-A 規格：牌桌骨架與視覺層級

### 2.1 這一段要做到

- 一眼看得出：**對手是誰、我手上有什麼、桌上押了多少、這一墩比大還比小、現在輪到我做什麼**
- 牌真的在桌上：雙方蓋下的牌放在綠絨桌的出牌位（對手在上、我在下）；翻牌結果也在桌上
- 底部只剩**一句問題＋主要按鈕**；次要資訊（試算細節、規則）收到「？」
- 六種手機大小都**不用捲動**；所有按鈕 ≥ 44px 高；什麼都不會蓋到手牌、按鈕、對手資訊、籌碼
- 這一段**不做動畫**（B、C 才做），但所有牌、籌碼、出牌位都改成**持久節點**，B、C 可以直接讓它們動

### 2.4 隱藏資訊規則（照舊、這一段要加測試）

- 對手的出牌位在翻牌前**只畫牌背**；DOM 裡不會有任何牌面資料（對手的牌 id 本來就不會在翻牌前送到手機上）
- 我蓋下的牌：牌背＋只有自己看得到的小標（「J♣」）；讀心結果只在我的畫面上顯示
- 棄牌的那墩：只公開大中小（跟現在一樣）

### 2.5 文字（A 段只動位置和層級；口語化在 D 段）

- 拿掉重複：自己的「剩 N 張：大中小」拿掉（自己的牌就在手上）；每張手牌下面的「大／中／小」字拿掉（D 段會給「?」說明和讀心時的提示）；技能從文字改成三個小圓章（用過的變灰）
- 對手的大中小留著（這是有用的情報），縮成「大2 中3 小1」
- 輸贏試算從 2 行縮成行動列的一行小字＋按鈕上的小字（接戰「補2」、棄牌「輸1」）；完整試算點「?」看
- 每墩紀錄：從展開式改成點「上一墩：…」打開的面板（不推版面）

### 2.6 P2 轉播在 A 段怎麼處理

- 字幕留在頂列中間一行（窄的時候只剩主播／公告，聊天室先不播）
- 節目小卡：牌桌上沒有空位了 → A 段一律用「標題列一行」的精簡模式；**正式的「旁邊一條＋重大事件進牌桌」在 E 段**
- 下注壓力暗角照舊；`__hbCast()` 照舊

### 2.7 技術做法

- **持久節點**：`lstable.ts` 改成「建一次、之後只更新」
  - 手牌：每張牌一個節點，用牌 id 當 key；鎖掉的牌從手牌**移到**我的出牌位（同一個節點，B 段直接加飛行動畫）
  - 出牌位、籌碼堆、方向徽章、疊池、結果緞帶：固定節點，只改內容和 class
  - 行動列按鈕：固定一組 `button[data-a]`，依狀態顯示／隱藏／改字（不再 `innerHTML` 整排重畫，按鈕不會閃）
- **版面**：CSS grid（`grid-template-rows: auto auto minmax(0,1fr) auto auto auto`）＋ `100dvh`；小螢幕用 `@media (max-height: …)` 縮出牌位和手牌，**不縮字**
- **新元件**（純 CSS，沿用木桌、紙張、綠絨、黑金細框、印章）：印章頭像、技能小圓章、籌碼堆（A 段靜態、C 段會動）、出牌位、方向徽章、結果緞帶
- **效能**：之後的動畫只動 `transform`／`opacity`；A 段不加任何持續動畫；減少動態照舊
- **不動**：`engine.ts`、`rules.ts`、伺服器、`net.ts`、協定、AI、導演、戰報

### 2.8 測試計畫

- 改寫 `laststand-layout.mjs`：六種大小 × 每個階段 → **不能捲動**、五區不重疊、按鈕 ≥ 44px、對手名牌／出牌位／籌碼／手牌／按鈕都在畫面裡
- 新增 `p25-a.mjs`：
  - 每一步檢查對手出牌位在翻牌前只有牌背（DOM 裡沒有牌面）
  - 鎖牌後那張牌離開手牌、出現在我的出牌位
  - 上一墩結果翻在桌上
  - 加注展開列可以加減、梭哈寫「每人押 N」
- 更新 `laststand-ui`、`lsai-ui`、`p2-cast` 裡跟舊結構有關的選擇器；`data-a` 不變
- 回歸：`npm test`、`two-sockets`、`laststand-room`、`two-phones`、`p15-ui`、`lsai-gate`、經典 `layout-check`
- 交付：六種大小每個階段的截圖、跟現況圖對照

### 2.9 驗收標準（A 段）

1. 六種手機大小、每個階段都不用捲動，什麼都沒被擋住
2. 對手、出牌位、方向、底注／疊池、我的手牌、現在的決定，一眼看得到
3. 鎖了的牌在桌上、不在手牌裡；翻牌前對手的牌只有牌背
4. 一次最多 4 顆按鈕，主按鈕明顯
5. 朋友連線、AI 測試、斷線重連、P2 轉播與戰報都照常

### 2.10 風險

- **測試大改**：版面測試要重寫 → 先寫新的檢查，再改畫面
- **P2 小卡沒地方放**：A 段先全部用精簡一行（E 段解決），所以 A 段的轉播會比現在「少演」
- **iOS Safari 的 `100dvh`**：舊版用 `-webkit-fill-available` 補；鍵盤不會出現在牌桌（沒有輸入框）
- **舊的 `#lsLog` 展開**：改成面板，版面測試要跟著改
